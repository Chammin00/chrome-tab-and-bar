# Chrome Tab & Bar - Antigravity Multi-Project Index Hub

This project connects all **42 project index files** across your Antigravity workspace directly into **Google Chrome**:
1. **Directly inside Google Chrome's Bookmarks Bar** as an organized folder (`Antigravity Index Files`) with 5 categorized subfolders.
2. **As an Unpacked Chrome Extension** (`manifest.json` Manifest V3) that turns your Chrome New Tab and Side Panel into an enterprise mission-control dashboard.
3. **As an Enterprise Full-Screen Web Dashboard** (`index.html`) following GitHub Primer dark tokens and High-Gloss Lacquer material optics.

---

## 🚀 How to View Your Index Files Inside Chrome

### Option 1: Chrome Bookmarks Bar (Native Dropdown Folder)
All 42 project index files are organized inside a folder named **`Antigravity Index Files`** on your Chrome bookmarks bar.

#### Instant 2-Click Import (Zero Downtime, Works While Chrome is Running):
1. In Google Chrome, go to: `chrome://bookmarks`
2. Click the **three vertical dots** in the top right corner.
3. Select **Import bookmarks**.
4. Choose the generated file:
   `G:\My Drive\Antigravity\Projects\chrome tab and bar\Antigravity_Index_Bookmarks.html`
5. Chrome will instantly create the folder on your Bookmarks Bar containing all 42 projects!

#### Automated Profile Injection (PowerShell):
If Chrome is closed, you can run the automated script to inject directly into your Chrome profile JSON:
```powershell
powershell -ExecutionPolicy Bypass -File "G:\My Drive\Antigravity\Projects\chrome tab and bar\Install-ChromeBookmarks.ps1"
```

---

### Option 2: Chrome New Tab & Side Panel Extension
You can load this dashboard directly into Chrome as an extension:
1. In Chrome, navigate to `chrome://extensions`
2. Enable **Developer mode** (toggle in top right).
3. Click **Load unpacked** (top left).
4. Select the folder: `G:\My Drive\Antigravity\Projects\chrome tab and bar`
5. Every new tab you open in Chrome will now display this full-screen interactive launcher with real-time search (`Ctrl+K`), category tabs, and 1-click index file launching!
